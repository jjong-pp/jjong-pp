# 실측 계획 — 답안을 추정에서 관측으로 바꾸는 작업

기준일 2026-08-14

---

## 0. 왜 하는가

공고 자격요건에 "생성형 AI 도구를 **실무에 적극 활용해본 분**"이 있고, 이 포지션의 설명에 "생성형 AI를 **업무 도구이자 분석 대상으로** 다루며"가 있다. 즉 회사가 원한다고 명시한 것이 **AI를 직접 두들겨 본 사람**이다.

이 문서는 문헌에서 읽은 변동성을 실제 관측으로 확인하고, PRD의 두 기능을 수동으로 한 번 실행해 보기 위한 파일럿 설계다. 실행 수 자체보다 **질문·환경·반복 조건을 기록하고 원문 판정을 검수하는 것**을 우선한다.

특히 문항 1의 기준 1(재현되는 등장)은 "LLM 답변은 비결정적이다"라는 전제 위에 서 있다. 이 전제를 **관측된 편차 수치로 뒷받침하면 주장이 사실이 되고, 그러지 못하면 어디선가 읽은 이야기로 남는다.**

부수 효과 하나 더 — 이 작업이 곧 `02_답안_문항2_PRD.md`의 F1을 손으로 한 번 돌려보는 일이다. 만들려는 제품을 수동으로 실행해 본 사람만 쓸 수 있는 문장이 PRD에 생긴다. 면접에서 "이 기능을 왜 이렇게 설계했나요"를 물으면 답이 이미 손에 있다.

## 1. 측정 설계

### 1-1. 대상 선정

과제 시나리오가 "구독형 협업툴 B2B SaaS"이므로 **실제 협업툴 카테고리를 그대로 측정한다.**

| 역할 | 대상 | 선정 이유 |
|---|---|---|
| 가상 자사 | **JANDI** | 국내 구독형 B2B 협업툴로 시나리오와 맞고, 공개된 요금·기능 정보를 사실 대조 기준으로 사용하기 쉬움 |
| 경쟁사 | Notion, Slack, Microsoft Teams, Asana, Monday 중 3~5개 | 답변에 실제로 등장하는 기본값들 |

**주의.** 측정 결과에 특정 회사에 대한 사실 오류가 나오더라도, 답안에는 **"모델이 사실과 다르게 서술한 사례"** 로 중립적으로 적는다. "○○사 정보가 틀렸다"는 형태로 쓰지 않는다. 측정 대상은 모델이지 그 회사가 아니다.

### 1-2. 규모

| 구분 | 의도군 | 대표 표현 | 환경 | 반복 | 총 실행 | 용도 |
|---|---:|---:|---:|---:|---:|---|
| **제출 전 한국어 축소 파일럿** | 3 | 의도군당 1개 | 3 | 3 | **27** | 질문 등록→실행→역할·사실 판정→집계→근거 저장 파이프라인 점검 |
| **제품의 월간 통제 UI 표본** | 4 | 총 6개 | 3개 UI | 2 | **36** | API 시계열과 실제 소비자 화면의 대표성 차이 점검 |

두 36/27 숫자는 다른 설계다. 제출 전 27회는 `A3 / B1 / E1`처럼 **세 의도군에서 대표 표현을 하나씩만 고른 축소 파일럿**이다. 데이터 흐름과 판정 절차가 작동하는지만 확인하며, 의도군마다 2~3개 표현을 운영하는 제품 설계의 타당성·지표 안정성·시장 효과를 검증한 것으로 해석하지 않는다. 월간 UI 36회는 제품 운영안이며, 제품에서는 경로·위험도·예산에 따라 반복 수를 사이클 설정으로 저장한다.

이 실행 수는 경로를 섞으라는 뜻이 아니다. **공식 API로 실행한 행만 공식 점수·추이 후보**가 되고, 브라우저에서 사람이 실행한 행은 `[통제 UI 표본]`으로만 기록한다. API를 실행하지 못하면 UI 관측 자체는 유효하지만, 공식 GEO 원점수나 API 시계열인 것처럼 제출하지 않는다.

우선 환경: ChatGPT · Gemini · Perplexity. 표시되는 인용과 검색 사용 여부는 서비스별로 다를 수 있으므로, 확인된 증거만 기록한다.

### 1-3. 측정 조건 고정 (PRD의 NFR-03에 해당)

- **공통:** 질문 버전·언어·지역·모델 계열을 고정하고, 한 질의의 설정 반복은 같은 날 같은 시간대에 몰아서 실행한다. 날짜가 섞이면 편차의 원인이 생성 변동인지 시점 차이인지 구분되지 않는다.
- **공식 API:** 고정 모델 스냅샷과 `search_policy`를 기록하고 응답별 `search_used`를 남긴다. 상태 없는 독립 요청으로 실행한다.
- **통제 UI:** 매번 새 대화로 시작하고 가능하면 로그아웃 또는 임시 채팅을 쓰며, 로그인·Memory·프로필·요금제·표시 모델·검색 모드·네트워크 지역을 기록한다. 이는 개인화를 제거한다는 보장이 아니라 요인을 줄이고 설명하기 위한 통제다.
- 두 경로 모두 모델 버전 또는 UI 표시 모델을 기록한다. UI 내부 빌드가 미공개면 `unknown`으로 두며 API와 같다고 추정하지 않는다.

### 1-4. 측정 경로 분리

- `api_standard`: 공식 점수·기준선·주간 추이·즉시 검증 변화량의 정본이다. 웹 검색을 사용할 수 있는 `available_auto / forced` 중 API가 실제 지원하는 정책만 쓰고, 실제 검색 사용 여부도 함께 저장한다. 검색을 끈 API 실험이 필요하면 별도 실험 로그에서 관리하며 이 `measurements.csv`와 MVP 집계 범위에는 넣지 않는다.
- `ui_check`: 실제 사용자 화면과 API 운영 기준 시계열 사이의 대표성 격차를 보는 별도 표본이다. 최초 기준 표본 후 월 1회 `상위 질문 의도군에서 선정한 대표 표현 6개 × ChatGPT·Gemini·Perplexity × 2회 = 36회`를 실행하고, API 추세 이상·제공사 UI/모델/검색 설정 변경·고객 제보·P0 발생 시 영향 범위만 추가 실행한다. 공식 점수에는 합산하지 않는다.
- UI 수집은 약관·승인 확인 전에는 **수동 또는 사용자 보조 방식**만 사용한다. 자동화는 승인 근거를 기록한 경우에만 별도 수집 모드로 허용한다.

## 2. 질의 세트

아래 질문은 **가상 계정용 후보 라이브러리**이며 실제 제품의 정본 질문이 아니다. F1에서는 고객의 문제와 구매 상황을 먼저 `intent_group_id`로 정의하고, 같은 의도를 자연스럽게 묻는 대표 표현 2~3개를 붙인다. 기대 사업 행동과 검증 가능한 브랜드 적합성의 근거를 확인한 뒤 사용자가 의도군의 포함 여부와 가중치를 확정한다.

- `intent_group_id`: 고객 문제·구매 상황 단위의 안정적인 집계 ID다. 예: `IG-A-50P-ADOPT`.
- `query_id`: 대표 표현의 ID이자 `expression_id`다. 한 `query_id`는 오직 하나의 `intent_group_id`에만 속한다. 문구를 실질적으로 바꾸면 새 `query_id`를 발급한다.
- `query_weight`: 대표 표현별 가중치가 아니라 **의도군 전체의 중요도**다. 같은 의도군의 모든 표현에는 같은 값을 복제 저장하고, 집계할 때 표현 평균을 먼저 낸 뒤 의도군에 가중치를 한 번만 적용한다.

| `intent_group_id` | 고객 문제·구매 상황 | `query_type` | 대표 표현(`query_id` = `expression_id`) |
|---|---|---|---|
| `IG-A-50P-ADOPT` | 직원 50명 안팎 조직이 첫 협업툴 도입 후보를 찾음 | 추천 | `A1` 50명 안팎 조직이 도입할 만한 협업툴 추천해줘<br>`A2` 직원 50명 정도인 스타트업에 맞는 협업 도구는 뭐야?<br>`A3` 50명 규모 회사에 맞는 협업툴 뭐가 좋아? |
| `IG-B-NOTION-ALT` | Notion을 쓰거나 검토 중인 팀이 대안을 찾음 | 대안 | `B1` Notion 대안 알려줘<br>`B2` Notion 대신 쓸 만한 협업툴이 있어?<br>`B3` Notion을 대체할 협업 도구를 추천해줘 |
| `IG-C-PRICE-COMPARE` | 구매 전 구독 비용과 요금 조건을 비교함 | 비교 | `C1` 협업툴 구독 요금을 비교해줘<br>`C2` 50명 기준으로 협업툴 비용을 비교해줘<br>`C3` 협업툴 가격 비교해줘 |
| `IG-D-KO-FIT` | 한국어 지원과 국내 조직 운영 적합성을 확인함 | 기능 | `D1` 국내 팀이 쓰기 편한 한국어 협업툴 추천해줘<br>`D2` 한국어 지원이 잘 되는 협업 도구 알려줘<br>`D3` 한국어 고객지원이 있는 협업툴은 뭐야? |
| `IG-E-JANDI-FACT` | JANDI를 검토하며 요금·기능·적합 조건을 사실 확인함 | 사실 검증 | `E1` JANDI의 현재 요금제, 핵심 협업 기능, 잘 맞는 조직 조건을 근거와 함께 설명해줘<br>`E2` JANDI의 최신 가격과 주요 기능을 공식 근거로 정리해줘 |

- 제출 전 27회 축소 파일럿: `A3 / B1 / E1`을 각 환경에서 3회 실행한다. 세 의도군의 표현을 하나씩만 쓰므로 **파이프라인 검증**이며 제품 타당성 검증이 아니다.
- 월간 통제 UI 36회: `A2 / A3 / B1 / B2 / C3 / D2`를 각 UI에서 2회 실행한다. 같은 의도군의 표현이 둘 이상 포함돼도 그 의도군의 가중치는 한 번만 적용한다.

`IG-E-JANDI-FACT`는 사실 정확성과 분류 파이프라인을 검증하기 위한 브랜드 지명 의도군이므로 무브랜드 노출률·추천률에는 합산하지 않는다.

핵심 열 예시:

```csv

```

**유효 사이클 규칙.** `intent_group_id`와 `query_id`는 공란일 수 없고, 전체 이력에서 같은 `query_id`는 하나의 `intent_group_id`에만 속해야 한다. 같은 의도군의 `query_weight`는 대표 표현 수·모델·반복과 무관하게 하나의 값이어야 한다. `affected_scope_pairs`에 선언한 모든 `질의×모델` 조합을 설정한 `expected_repeats`만큼 실행하고, 중복·실패·누락이 없어야 한다. 공식 API는 조합당 최소 3회, UI는 사전에 선언한 반복 수를 사용한다. API 기준선은 전체 점수 범위의 정본이며, API 주간 사이클은 범위와 경로·검색·설정·모델 스냅샷이 같아야 변화량을 낸다. API 즉시 검증도 같은 원칙으로 영향 범위만 비교한다. UI 표본은 별도 요약하며 어떤 경우에도 전체 GEO 점수에 섞지 않는다.

**점수 집계 순서.** 각 대표 표현(`query_id`)의 모델·반복 결과를 먼저 평균하고, 그 표현 평균들을 같은 `intent_group_id` 안에서 다시 동일 비중으로 평균한다. 마지막에 의도군 평균에 `query_weight`를 한 번만 적용해 전체 가중 평균을 낸다. 따라서 같은 의도군에 표현을 두세 개 넣어도 의도군의 총 가중치가 두세 배로 부풀지 않는다.

P0는 두 경로의 사람이 확인한 이슈를 모두 등급 상한에 반영한다. 같은 사실 문제는 `issue_family_id`로 묶어 표시하되 API·UI의 `issue_id`와 상태는 분리한다. 어느 경로의 P0든 최초 확정한 `issue_origin_cycle_id`를 비교 기준으로 삼아 `issue_origin_route`·`issue_confirmed_scope_pairs`·조건 버전이 모두 같은 유효한 즉시 재검증을 완주하고 사람이 승인해야 해제한다.

## 4. 집계 스크립트

각 경로에서 수집한 응답을 CSV에 기록한 뒤 돌린다. 공식 API 점수와 UI 대표성 표본이 분리되어 출력된다.

```python
import pandas as pd

FULL_CYCLE_TYPES = {"기준선", "주간"}
CAP_STATUSES = {"활성", "해제 후보", "재개방"}
API_STANDARD_SEARCH_POLICIES = {"available_auto", "forced"}
UI_COLLECTION_MODES = {"manual", "user_assisted", "automated_approved"}
UI_CHECK_REASONS = {
    "initial",
    "monthly",
    "api_anomaly",
    "provider_change",
    "customer_report",
    "p0_event",
    "p0_verification",
}
SCORE_EXCLUDED_QUERY_TYPES = {"사실 검증"}
REQUIRED_ID_COLUMNS = {"intent_group_id", "query_id", "query_weight"}
SNAPSHOT_PAIR_FIELDS = [
    "search_policy",
    "route_config_version",
    "surface",
    "session_mode",
    "locale",
    "location",
    "model_version",
    "intent_group_id",
    "query_weight",
]
SNAPSHOT_CYCLE_FIELDS = [
    "query_set_version",
    "competitor_set_version",
    "score_formula_version",
    "analysis_schema_version",
]

history = pd.read_csv("measurements.csv")
missing_id_columns = REQUIRED_ID_COLUMNS - set(history.columns)
if missing_id_columns:
    raise ValueError(
        "CSV 필수 열 누락: " + ", ".join(sorted(missing_id_columns))
    )
history["_row_order"] = range(len(history))
history["_run_at"] = pd.to_datetime(history["run_at"], errors="coerce")
history["_trial"] = pd.to_numeric(history["trial"], errors="coerce")


def clean_text(series):
    return series.fillna("").astype(str).str.strip()


def validate_query_intent_mapping(frame):
    reasons = []
    query_ids = clean_text(frame["query_id"])
    intent_group_ids = clean_text(frame["intent_group_id"])
    if query_ids.eq("").any():
        reasons.append("query_id 필수값 누락")
    if intent_group_ids.eq("").any():
        reasons.append("intent_group_id 필수값 누락")

    keyed = frame.assign(
        _query_id=query_ids,
        _intent_group_id=intent_group_ids,
    )
    keyed = keyed[
        keyed["_query_id"].ne("") & keyed["_intent_group_id"].ne("")
    ]
    mapping_counts = keyed.groupby("_query_id")["_intent_group_id"].nunique()
    conflicts = mapping_counts[mapping_counts.gt(1)].index.tolist()
    if conflicts:
        preview = ", ".join(conflicts[:5])
        suffix = " 외" if len(conflicts) > 5 else ""
        reasons.append(
            f"같은 query_id가 여러 intent_group_id에 속함: {preview}{suffix}"
        )
    return reasons


def one_value(group, column):
    values = clean_text(group[column])
    values = values[values != ""].unique().tolist()
    return values[0] if len(values) == 1 else None


def parse_scope_pairs(value):
    pairs = set()
    for token in str(value or "").split(";"):
        token = token.strip()
        if not token:
            continue
        if "@" not in token:
            raise ValueError(f"영향 범위 형식 오류: {token}")
        query_id, model = (part.strip() for part in token.split("@", 1))
        if not query_id or not model:
            raise ValueError(f"영향 범위 형식 오류: {token}")
        pairs.add((query_id, model))
    return pairs


def declared_scope(group):
    scope_version = one_value(group, "affected_scope_version")
    scope_manifest = one_value(group, "affected_scope_pairs")
    if (
        not scope_version
        or not scope_manifest
        or clean_text(group["affected_scope_version"]).eq("").any()
        or clean_text(group["affected_scope_pairs"]).eq("").any()
    ):
        raise ValueError("범위 버전 또는 목록 누락")
    return scope_version, parse_scope_pairs(scope_manifest)


def declared_repeats(group):
    numeric = pd.to_numeric(group["expected_repeats"], errors="coerce")
    values = numeric.dropna().unique()
    if numeric.isna().any() or len(values) != 1 or values[0] % 1 != 0 or values[0] < 1:
        raise ValueError("expected_repeats는 사이클 내 하나의 양의 정수여야 함")
    return int(values[0])


def subset_pairs(group, pairs):
    keys = list(zip(clean_text(group["query_id"]), clean_text(group["model"])))
    return group[pd.Series([key in pairs for key in keys], index=group.index)]


def validate_cycle(group, expected_pairs, expected_repeats):
    expected_keys = {
        (query_id, model, trial)
        for query_id, model in expected_pairs
        for trial in range(1, expected_repeats + 1)
    }
    actual_keys = list(zip(
        clean_text(group["query_id"]),
        clean_text(group["model"]),
        group["_trial"],
    ))
    actual_key_set = set(actual_keys)
    missing = expected_keys - actual_key_set
    extras = actual_key_set - expected_keys
    duplicates = len(actual_keys) - len(actual_key_set)
    failed = int((clean_text(group["run_status"]) != "성공").sum())
    valid = bool(expected_pairs) and not missing and not extras and not duplicates and not failed
    reasons = []
    if not expected_pairs:
        reasons.append("기대 범위 없음")
    if missing:
        reasons.append(f"누락 {len(missing)}건")
    if extras:
        reasons.append(f"범위 밖 실행 {len(extras)}건")
    if duplicates:
        reasons.append(f"중복 {duplicates}건")
    if failed:
        reasons.append(f"실패 {failed}건")
    return valid, reasons


def pair_field_map(group, column):
    result = {}
    keyed = group.assign(
        _query_id=clean_text(group["query_id"]),
        _model=clean_text(group["model"]),
    )
    for pair, rows in keyed.groupby(["_query_id", "_model"]):
        if clean_text(rows[column]).eq("").any():
            return None
        value = one_value(rows, column)
        if value is None:
            return None
        result[pair] = value
    return result


def cycle_order_ids(frame):
    if frame.empty:
        return []
    return (
        frame.groupby("cycle_id", dropna=False)
        .agg(last_run=("_run_at", "max"), last_row=("_row_order", "max"))
        .sort_values(["last_run", "last_row"], na_position="first")
        .index
        .tolist()
    )


def validate_route_cycle(group, expected_route=None):
    reasons = []
    route = one_value(group, "measurement_route")
    condition = one_value(group, "condition_version")
    if not route or clean_text(group["measurement_route"]).eq("").any():
        reasons.append("measurement_route 누락 또는 혼합")
    elif expected_route and route != expected_route:
        reasons.append(f"measurement_route={route}")
    if not condition or clean_text(group["condition_version"]).eq("").any():
        reasons.append("condition_version 누락 또는 혼합")

    for field in SNAPSHOT_CYCLE_FIELDS:
        if not one_value(group, field) or clean_text(group[field]).eq("").any():
            reasons.append(f"{field} 누락 또는 혼합")

    for field in SNAPSHOT_PAIR_FIELDS:
        if pair_field_map(group, field) is None:
            reasons.append(f"질의×모델별 {field} 누락 또는 혼합")

    policies = clean_text(group["search_policy"])
    used = clean_text(group["search_used"])
    if route == "api_standard":
        invalid_policy = ~policies.isin(API_STANDARD_SEARCH_POLICIES)
        invalid_used = (
            (policies.eq("forced") & ~used.eq("yes"))
            | (policies.eq("available_auto") & ~used.isin(["yes", "no", "unknown"]))
        )
        if invalid_policy.any():
            reasons.append("API에 부적합한 search_policy")
        if invalid_used.any():
            reasons.append("search_policy와 search_used 불일치")
        if not clean_text(group["collection_mode"]).eq("api").all():
            reasons.append("API collection_mode는 api여야 함")
        if clean_text(group["ui_check_reason"]).ne("").any():
            reasons.append("API ui_check_reason은 공란이어야 함")
    elif route == "ui_check":
        if not policies.eq("ui_default").all():
            reasons.append("UI search_policy는 ui_default여야 함")
        if not used.isin(["yes", "no", "unknown"]).all():
            reasons.append("UI search_used 값 오류")
        modes = clean_text(group["collection_mode"])
        if not modes.isin(UI_COLLECTION_MODES).all():
            reasons.append("UI collection_mode 값 오류")
        automated = modes.eq("automated_approved")
        if (automated & clean_text(group["automation_approval_id"]).eq("")).any():
            reasons.append("UI 자동화 승인 ID 누락")
        if not clean_text(group["ui_check_reason"]).isin(UI_CHECK_REASONS).all():
            reasons.append("UI ui_check_reason 누락 또는 값 오류")
    elif route:
        reasons.append(f"지원하지 않는 measurement_route={route}")
    return not reasons, reasons


def validate_metric_fields(group):
    reasons = []
    reasons.extend(validate_query_intent_mapping(group))
    intent_group_ids = clean_text(group["intent_group_id"])
    query_ids = clean_text(group["query_id"])
    weights = pd.to_numeric(group["query_weight"], errors="coerce")
    appeared = pd.to_numeric(group["own_appeared"], errors="coerce")
    recommended = pd.to_numeric(group["own_recommended"], errors="coerce")
    roles = clean_text(group["own_role"])
    allowed_roles = {"추천", "비교·검토 후보", "단순 언급", "주의·비추천", "미노출"}

    if (
        weights.isna().any()
        or (~weights.between(1, 5)).any()
        or (weights % 1 != 0).any()
    ):
        reasons.append("query_weight는 1~5 정수여야 함")
    weighted = group.assign(
        _intent_group_id=intent_group_ids,
        _query_id=query_ids,
        _query_weight=weights,
    )
    if any(rows["_query_weight"].nunique(dropna=False) != 1 for _, rows in weighted.groupby("_query_id")):
        reasons.append("같은 query_id의 query_weight가 모델·반복 간 다름")
    if any(
        rows["_query_weight"].nunique(dropna=False) != 1
        for _, rows in weighted.groupby("_intent_group_id")
    ):
        reasons.append("같은 intent_group_id의 query_weight가 대표 표현·모델·반복 간 다름")

    if appeared.isna().any() or (~appeared.isin([0, 1])).any():
        reasons.append("own_appeared는 0 또는 1이어야 함")
    if recommended.isna().any() or (~recommended.isin([0, 1])).any():
        reasons.append("own_recommended는 0 또는 1이어야 함")
    if (recommended > appeared).any():
        reasons.append("own_recommended=1이면 own_appeared=1이어야 함")
    if (~roles.isin(allowed_roles)).any():
        reasons.append("own_role 값 오류")
    if ((appeared.eq(0) & ~roles.eq("미노출")) | (appeared.eq(1) & roles.eq("미노출"))).any():
        reasons.append("own_appeared와 own_role 불일치")
    if ((recommended.eq(1) & ~roles.eq("추천")) | (roles.eq("추천") & ~recommended.eq(1))).any():
        reasons.append("own_recommended와 추천 역할 불일치")
    if (appeared.eq(1) & clean_text(group["evidence_text"]).eq("")).any():
        reasons.append("자사 등장 행의 evidence_text 누락")

    ranks = pd.to_numeric(group["own_rank"], errors="coerce")
    rank_text = clean_text(group["own_rank"])
    if (
        (recommended.eq(1) & (ranks.isna() | (ranks < 1) | (ranks % 1 != 0))).any()
        or (recommended.eq(0) & rank_text.ne("")).any()
    ):
        reasons.append("own_rank는 추천 행의 양의 정수여야 하고 미추천 행은 공란이어야 함")

    for appeared_text, recommended_text in zip(
        clean_text(group["competitors_appeared"]),
        clean_text(group["competitors_recommended"]),
    ):
        appeared_list = [x.strip() for x in appeared_text.split(";") if x.strip()]
        recommended_list = [x.strip() for x in recommended_text.split(";") if x.strip()]
        if len(appeared_list) != len(set(appeared_list)) or len(recommended_list) != len(set(recommended_list)):
            reasons.append("경쟁사 목록 중복")
            break
        if not set(recommended_list).issubset(set(appeared_list)):
            reasons.append("추천 경쟁사는 등장 경쟁사 목록에 포함되어야 함")
            break
    return reasons


def validate_measurement_cycle(group, expected_route=None):
    try:
        scope_version, pairs = declared_scope(group)
        repeats = declared_repeats(group)
    except ValueError as exc:
        return False, [str(exc)], None, None, None
    route_valid, route_reasons = validate_route_cycle(group, expected_route)
    cycle_valid, cycle_reasons = validate_cycle(group, pairs, repeats)
    metric_reasons = validate_metric_fields(group)
    reasons = route_reasons + cycle_reasons + metric_reasons
    if one_value(group, "measurement_route") == "api_standard" and repeats < 3:
        reasons.append("공식 API expected_repeats는 최소 3이어야 함")
    return not reasons, reasons, scope_version, pairs, repeats


def comparison_errors(current, reference, pairs, current_repeats, reference_repeats):
    reasons = []
    if current_repeats != reference_repeats:
        reasons.append(
            f"expected_repeats 불일치 ({reference_repeats} -> {current_repeats})"
        )
    if one_value(current, "measurement_route") != one_value(reference, "measurement_route"):
        reasons.append("measurement_route 불일치")
    if one_value(current, "condition_version") != one_value(reference, "condition_version"):
        reasons.append("condition_version 불일치")
    for field in SNAPSHOT_CYCLE_FIELDS:
        if one_value(current, field) != one_value(reference, field):
            reasons.append(f"{field} 불일치")
    for field in SNAPSHOT_PAIR_FIELDS:
        if pair_field_map(current, field) != pair_field_map(reference, field):
            reasons.append(f"질의×모델별 {field} 불일치")
    return reasons


def search_use_rate(group):
    used = clean_text(group["search_used"])
    known = used.isin(["yes", "no"])
    return used[known].eq("yes").mean() if known.any() else None


def completed_pairs(group, pairs, repeats):
    successful = group[clean_text(group["run_status"]).eq("성공")]
    keys = set(zip(
        clean_text(successful["query_id"]),
        clean_text(successful["model"]),
        successful["_trial"],
    ))
    return {
        pair for pair in pairs
        if all((pair[0], pair[1], trial) in keys for trial in range(1, repeats + 1))
    }


def representative_roles(group):
    result = {}
    keyed = group.assign(
        _query_id=clean_text(group["query_id"]),
        _model=clean_text(group["model"]),
        _role=clean_text(group["own_role"]),
    )
    for pair, rows in keyed.groupby(["_query_id", "_model"]):
        counts = rows.loc[
            ~rows["_role"].isin(["", "미노출"]), "_role"
        ].value_counts()
        if counts.empty:
            continue
        winners = counts[counts.eq(counts.max())].index.tolist()
        if len(winners) == 1:
            result[pair] = winners[0]
    return result


def intent_metric_tables(group, metric_columns):
    """응답 행 -> 대표 표현 평균 -> 의도군 평균을 순서대로 만든다."""
    data = group[
        ~clean_text(group["query_type"]).isin(SCORE_EXCLUDED_QUERY_TYPES)
    ].copy()
    if data.empty:
        raise ValueError("점수 산출 대상 질문이 없습니다.")

    data["_intent_group_id"] = clean_text(data["intent_group_id"])
    data["_query_id"] = clean_text(data["query_id"])
    data["_query_weight"] = pd.to_numeric(data["query_weight"], errors="coerce")
    if data["_intent_group_id"].eq("").any() or data["_query_id"].eq("").any():
        raise ValueError("intent_group_id·query_id 필수값이 비어 있습니다.")
    if data["_query_weight"].isna().any():
        raise ValueError("query_weight가 비어 있어 집계할 수 없습니다.")

    for column in metric_columns:
        data[column] = pd.to_numeric(data[column], errors="coerce")
        if data[column].isna().any():
            raise ValueError(f"{column} 값이 비어 있어 집계할 수 없습니다.")

    weight_counts = data.groupby("_intent_group_id")["_query_weight"].nunique(
        dropna=False
    )
    if weight_counts.gt(1).any():
        raise ValueError("같은 의도군 안에서 query_weight가 다릅니다.")

    expression_metrics = (
        data.groupby(["_intent_group_id", "_query_id"], as_index=False)[
            metric_columns
        ]
        .mean()
        .rename(
            columns={
                "_intent_group_id": "intent_group_id",
                "_query_id": "query_id",
            }
        )
    )
    intent_metrics = (
        expression_metrics.groupby("intent_group_id", as_index=False)[metric_columns]
        .mean()
    )
    group_weights = (
        data.groupby("_intent_group_id")["_query_weight"].first()
    )
    intent_metrics["query_weight"] = intent_metrics["intent_group_id"].map(
        group_weights
    )
    return expression_metrics, intent_metrics


def competitor_weighted_recommendation_scores(group):
    """경쟁사도 표현 평균→의도군 평균 뒤 의도군 가중치를 한 번만 적용한다."""
    data = group.copy()
    recommendation_sets = clean_text(data["competitors_recommended"]).apply(
        lambda value: {item.strip() for item in value.split(";") if item.strip()}
    )
    competitor_names = sorted(set().union(*recommendation_sets.tolist()))
    if not competitor_names:
        return pd.Series(dtype=float)

    metric_columns = []
    column_to_name = {}
    for index, competitor_name in enumerate(competitor_names):
        column = f"_competitor_{index}"
        data[column] = recommendation_sets.apply(
            lambda values, name=competitor_name: int(name in values)
        )
        metric_columns.append(column)
        column_to_name[column] = competitor_name

    _, intent_metrics = intent_metric_tables(data, metric_columns)
    weights = intent_metrics["query_weight"]
    scores = {
        column_to_name[column]: (weights * intent_metrics[column]).sum()
        for column in metric_columns
    }
    return pd.Series(scores, dtype=float).sort_values(ascending=False)


def weighted_metrics(group):
    _, intent_metrics = intent_metric_tables(
        group, ["own_appeared", "own_recommended"]
    )
    weights = intent_metrics["query_weight"]
    if weights.sum() == 0:
        raise ValueError("가중치·노출·추천 값이 비어 있어 집계할 수 없습니다.")
    return (
        (weights * intent_metrics["own_appeared"]).sum() / weights.sum(),
        (weights * intent_metrics["own_recommended"]).sum() / weights.sum(),
    )


def print_p0_guardrail(all_history):
    print("\n[P0 품질 가드레일 - 모든 측정 경로]")
    issue_rows = all_history[clean_text(all_history["issue_id"]) != ""].copy()
    if issue_rows.empty:
        print("사람이 확인한 P0 이슈: 0개 / 품질 가드레일: 미적용")
        return

    issue_rows["_issue_id"] = clean_text(issue_rows["issue_id"])
    p0_rows = issue_rows[issue_rows["error_review"].eq("중대(P0)")].copy()
    p0_issue_ids = set(p0_rows["_issue_id"])
    if not p0_issue_ids:

        return
    p0_families = clean_text(p0_rows["issue_family_id"])

        status_rows.sort_values(["_run_at", "_row_order"], na_position="first")
        .groupby("_issue_id", as_index=False)
        .tail(1)
    )
    latest_p0 = latest_status[latest_status["_issue_id"].isin(p0_issue_ids)].copy()

    origin_by_issue = {}
    origin_cycle_by_issue = {}
    confirmed_scope_by_issue = {}
    origin_errors = set()
    for issue_id, rows in p0_rows.groupby("_issue_id"):
        family_id = one_value(rows, "issue_family_id")
        origin = one_value(rows, "issue_origin_route")
        origin_cycle = one_value(rows, "issue_origin_cycle_id")
        confirmed_scope_text = one_value(rows, "issue_confirmed_scope_pairs")
        actual_p0_pairs = set(zip(
            clean_text(rows["query_id"]),
            clean_text(rows["model"]),
        ))
        if rows["_run_at"].isna().any():
            first_p0_cycle = None
            first_p0_route = None
        else:
            first_p0_row = rows.sort_values(
                ["_run_at", "_row_order"]
            ).iloc[0]
            first_p0_cycle = str(first_p0_row["cycle_id"]).strip()
            first_p0_route = str(first_p0_row["measurement_route"]).strip()
        try:
            confirmed_scope = parse_scope_pairs(confirmed_scope_text)
        except ValueError:
            confirmed_scope = set()
        fields_complete = (
            clean_text(rows["issue_family_id"]).eq(family_id).all()
            and clean_text(rows["issue_origin_route"]).eq(origin).all()
            and clean_text(rows["issue_origin_cycle_id"]).eq(origin_cycle).all()
            and clean_text(rows["issue_confirmed_scope_pairs"]).eq(
                confirmed_scope_text
            ).all()
        )
        if (
            not family_id
            or origin not in {"api_standard", "ui_check"}
            or not origin_cycle
            or not confirmed_scope
            or not fields_complete
            or origin_cycle != first_p0_cycle
            or origin != first_p0_route
            or not actual_p0_pairs.issubset(confirmed_scope)
        ):
            origin_errors.add(issue_id)
        else:
            origin_by_issue[issue_id] = origin
            origin_cycle_by_issue[issue_id] = origin_cycle
            confirmed_scope_by_issue[issue_id] = confirmed_scope

    latest_ids = set(latest_p0["_issue_id"])
    missing_status = p0_issue_ids - latest_ids
    latest_status_values = clean_text(latest_p0["issue_status"])
    invalid_status = set(
        latest_p0.loc[
            ~latest_status_values.isin(CAP_STATUSES | {"해제"}), "_issue_id"
        ]
    )
    active = latest_p0[latest_status_values.isin(CAP_STATUSES)]
    released = latest_p0[clean_text(latest_p0["issue_status"]).eq("해제")].copy()
    release_invalid = set(origin_errors) | missing_status | invalid_status
    for _, row in released.iterrows():
        issue_id = row["_issue_id"]
        origin_route = origin_by_issue.get(issue_id)
        origin_cycle_id = origin_cycle_by_issue.get(issue_id)
        confirmed_scope = confirmed_scope_by_issue.get(issue_id)
        audit_ok = (
            pd.notna(pd.to_datetime(row["released_at"], errors="coerce"))
            and str(row["released_by"] if pd.notna(row["released_by"]) else "").strip() != ""
            and str(row["verification_result"]).strip() in {"통과", "미등장으로 미재현"}
        )
        if not audit_ok:
            release_invalid.add(issue_id)
            continue
        if str(row["measurement_route"]).strip() != origin_route:
            release_invalid.add(issue_id)
            continue
        release_cycle = all_history[all_history["cycle_id"].eq(row["cycle_id"])].copy()
        valid_release, _, _, release_pairs, release_repeats = validate_measurement_cycle(
            release_cycle, origin_route
        )
        comparison_id = one_value(release_cycle, "comparison_cycle_id")
        verification_targets = clean_text(release_cycle["verification_issue_id"])
        verification_results = clean_text(release_cycle["verification_result"])
        if (
            not valid_release
            or one_value(release_cycle, "cycle_type") != "즉시 검증"
            or comparison_id != origin_cycle_id
            or release_pairs != confirmed_scope
            or not verification_targets.eq(issue_id).all()
            or not verification_results.isin(
                ["통과", "미등장으로 미재현"]
            ).all()
            or (
                clean_text(release_cycle["issue_id"]).eq(issue_id)
                & clean_text(release_cycle["error_review"]).eq("중대(P0)")
            ).any()
        ):
            release_invalid.add(issue_id)
            continue

        reference_cycle = all_history[
            all_history["cycle_id"].eq(comparison_id)
        ].copy()
        reference_valid, _, _, reference_pairs, reference_repeats = (
            validate_measurement_cycle(reference_cycle, origin_route)
        )
        origin_issue_present = (
            clean_text(reference_cycle["issue_id"]).eq(issue_id)
            & clean_text(reference_cycle["error_review"]).eq("중대(P0)")
        ).any()
        if (
            not reference_valid
            or not origin_issue_present
            or not release_pairs.issubset(reference_pairs)
        ):
            release_invalid.add(issue_id)
            continue
        reference_scope = subset_pairs(reference_cycle, release_pairs)
        reference_scope_valid, _ = validate_cycle(
            reference_scope, release_pairs, reference_repeats
        )
        if (
            not reference_scope_valid
            or comparison_errors(
                release_cycle,
                reference_scope,
                release_pairs,
                release_repeats,
                reference_repeats,
            )
        ):
            release_invalid.add(issue_id)

    reopened = latest_p0[clean_text(latest_p0["issue_status"]).eq("재개방")].copy()
    reopen_invalid = set()
    for _, row in reopened.iterrows():
        if (
            pd.isna(pd.to_datetime(row["reopened_at"], errors="coerce"))
            or str(row["reopened_by"] if pd.notna(row["reopened_by"]) else "").strip() == ""
        ):
            reopen_invalid.add(row["_issue_id"])

    capped_ids = set(active["_issue_id"]) | release_invalid
    print(
        f"사람이 확인한 사실 문제: {p0_families.nunique()}개 / "
        f"경로별 P0 레코드: {len(p0_issue_ids)}개 / "
        f"등급 상한 적용 레코드: {len(capped_ids)}개"
    )
    if origin_errors:
        print(f"기원 경로 감사 오류: {', '.join(sorted(origin_errors))} - 등급 상한 유지")
    if missing_status or invalid_status:
        status_errors = sorted(missing_status | invalid_status)
        print(f"P0 상태 감사 오류: {', '.join(status_errors)} - 등급 상한 유지")
    if release_invalid:
        print(
            "해제 감사·경로 오류: "
            f"{', '.join(sorted(release_invalid))} - 등급 상한 유지"
        )
    if reopen_invalid:
        print(
            "재개방 감사 오류: "
            f"{', '.join(sorted(reopen_invalid))} - 등급 상한 유지"
        )
    if capped_ids:
        print("품질 가드레일: 적용 - 원점수 보존 / 최종 등급 주의 또는 위험")
    else:
        print("품질 가드레일: 미적용")


def print_ui_summary(all_history):
    print("\n[UI 대표성 표본 - 공식 API 점수와 합산하지 않음]")
    ui_rows = all_history[
        clean_text(all_history["measurement_route"]).eq("ui_check")
        & clean_text(all_history["cycle_type"]).eq("UI 표본")
    ]
    ui_cycle_ids = cycle_order_ids(ui_rows)
    if not ui_cycle_ids:
        print("UI 표본 없음")
        return

    ui_cycle_id = ui_cycle_ids[-1]
    ui = all_history[all_history["cycle_id"].eq(ui_cycle_id)].copy()
    ui_valid, ui_reasons, _, ui_pairs, ui_repeats = validate_measurement_cycle(
        ui, "ui_check"
    )
    if ui_pairs is None or ui_repeats is None:
        print(f"{ui_cycle_id}: 요약 불가 ({', '.join(ui_reasons)})")
        return

    ui_scope = subset_pairs(ui, ui_pairs)
    ui_complete_pairs = completed_pairs(ui_scope, ui_pairs, ui_repeats)
    ui_completion = len(ui_complete_pairs) / len(ui_pairs) if ui_pairs else 0
    ui_success = ui_scope[clean_text(ui_scope["run_status"]).eq("성공")].copy()
    ui_success = ui_success.drop_duplicates(["query_id", "model", "trial"], keep="last")
    print(
        f"{ui_cycle_id} [{one_value(ui, 'ui_check_reason')}]: 표본 완료 {ui_completion:.1%} "
        f"({len(ui_complete_pairs)}/{len(ui_pairs)} 질의×모델)"
    )
    if not ui_valid:
        print(f"UI 표본 유효성 경고: {', '.join(ui_reasons)}")
        print("UI 가중 노출·추천 및 API↔UI 비교: 유효하지 않은 표본으로 산출하지 않음")
        return
    if ui_success.empty:
        print("UI 성공 응답 없음")
        return
    ui_exposure, ui_recommendation = weighted_metrics(ui_success)
    print(f"UI 가중 노출 {ui_exposure:.1%} / 추천 {ui_recommendation:.1%}")

    reference_id = one_value(ui, "reference_api_cycle_id")
    if not reference_id:
        print("API 대조 불가: reference_api_cycle_id 미기록 (UI 자체 요약만 유효)")
        return
    api = all_history[all_history["cycle_id"].eq(reference_id)].copy()
    if api.empty:
        print(f"API 대조 불가: {reference_id} 없음 (UI 자체 요약만 유효)")
        return
    api_valid, api_reasons, _, api_pairs, api_repeats = validate_measurement_cycle(
        api, "api_standard"
    )
    if not api_valid:
        print(f"API 대조 불가: {reference_id} 유효성 오류 ({', '.join(api_reasons)})")
        return

    matched_pairs = ui_pairs & api_pairs
    api_scope = subset_pairs(api, matched_pairs)
    api_complete_pairs = completed_pairs(api_scope, matched_pairs, api_repeats)
    matched_complete = ui_complete_pairs & api_complete_pairs
    matched_completion = len(matched_complete) / len(ui_pairs) if ui_pairs else 0
    print(
        "API↔UI matched scope completion: "
        f"{matched_completion:.1%} ({len(matched_complete)}/{len(ui_pairs)})"
    )
    if not matched_complete:
        print("API↔UI 격차·대표역할 일치: 비교 불가")
        return

    ui_matched = subset_pairs(ui_success, matched_complete)
    api_matched = subset_pairs(api, matched_complete)
    if one_value(ui_matched, "condition_version") != one_value(api_matched, "condition_version"):
        print("API↔UI 격차·대표역할 일치: condition_version 불일치로 비교 불가")
        return
    if one_value(ui_matched, "query_set_version") != one_value(api_matched, "query_set_version"):
        print("API↔UI 격차·대표역할 일치: query_set_version 불일치로 비교 불가")
        return
    if pair_field_map(ui_matched, "model_version") != pair_field_map(api_matched, "model_version"):
        print(
            "주의: API 스냅샷과 UI 표시/추정 모델 버전이 다르거나 미공개입니다. "
            "아래 값은 동일 모델 비교가 아니라 제품 표면 간 대표성 격차입니다."
        )
    if pair_field_map(ui_matched, "intent_group_id") != pair_field_map(api_matched, "intent_group_id"):
        print("API↔UI 격차·대표역할 일치: 질문-의도군 매핑 불일치로 비교 불가")
        return
    if pair_field_map(ui_matched, "query_weight") != pair_field_map(api_matched, "query_weight"):
        print("API↔UI 격차·대표역할 일치: 의도군 query_weight 불일치로 비교 불가")
        return

    api_exposure, api_recommendation = weighted_metrics(api_matched)
    matched_ui_exposure, matched_ui_recommendation = weighted_metrics(ui_matched)
    exposure_gap = (matched_ui_exposure - api_exposure) * 100
    recommendation_gap = (matched_ui_recommendation - api_recommendation) * 100
    if (
        one_value(ui_matched, "analysis_schema_version")
        != one_value(api_matched, "analysis_schema_version")
    ):
        print(
            f"API↔UI 노출 격차: 방향(UI-API) {exposure_gap:+.1f}%p / "
            f"절대격차 {abs(exposure_gap):.1f}%p"
        )
        print(
            "추천 격차·대표역할 일치: analysis_schema_version 불일치로 비교 불가 "
            "(동일 버전으로 원문 재분석 필요)"
        )
        return
    print(
        "API↔UI 격차: "
        f"방향(UI-API) 노출 {exposure_gap:+.1f}%p / 추천 {recommendation_gap:+.1f}%p; "
        f"절대격차 노출 {abs(exposure_gap):.1f}%p / 추천 {abs(recommendation_gap):.1f}%p"
    )
    ui_roles = representative_roles(ui_matched)
    api_roles = representative_roles(api_matched)
    ui_appeared_mask = pd.to_numeric(ui_matched["own_appeared"], errors="coerce").eq(1)
    api_appeared_mask = pd.to_numeric(api_matched["own_appeared"], errors="coerce").eq(1)
    ui_appeared_pairs = set(zip(
        clean_text(ui_matched.loc[ui_appeared_mask, "query_id"]),
        clean_text(ui_matched.loc[ui_appeared_mask, "model"]),
    ))
    api_appeared_pairs = set(zip(
        clean_text(api_matched.loc[api_appeared_mask, "query_id"]),
        clean_text(api_matched.loc[api_appeared_mask, "model"]),
    ))
    role_pairs = set(ui_roles) & set(api_roles) & ui_appeared_pairs & api_appeared_pairs
    if role_pairs:
        agreements = sum(ui_roles[pair] == api_roles[pair] for pair in role_pairs)
        print(f"대표역할 일치: {agreements / len(role_pairs):.1%} ({agreements}/{len(role_pairs)})")
    else:
        print("대표역할 일치: 비교 불가")
```

## 6. 시간이 없다면

과제 마감이 촉박하면 우선순위는 이 순서다.

1. 접근 가능한 한 환경에서 `A3 / B1 / E1`을 각 3회 실행해 최소 9회 원문을 먼저 검수한다. 이는 질문 등록·분류·근거 저장 파이프라인 점검이다.
2. 세 환경에 모두 접근할 수 있으면 같은 세 표현을 확장해 총 27회를 완주한다. 의도군당 표현 하나이므로 제품 타당성 검증으로 격상하지 않는다.
3. API 자격 증명이 없으면 외부 유료 호출을 자동으로 가정하지 않는다. UI에서 실행한 결과는 `[통제 UI 관측]`으로만 기록하며 공식 원점수·추이에 넣지 않는다.
4. 실행하지 못한 숫자는 만들지 않는다. 최종 본문은 `[실측]` 빈 문장을 삭제하고, 결과가 확보되면 가장 강한 발견 한 건만 추가한다.

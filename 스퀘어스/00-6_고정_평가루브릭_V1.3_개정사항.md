# 스퀘어스 PM 과제 고정 평가 루브릭 V1.3 개정사항

제정일: 2026년 8월 17일  
기준 문서: `00-4_고정_평가루브릭_V1.2.md`  
적용 방식: V1.2의 모든 기준을 유지하되, 이 문서가 명시한 항목만 교체·추가한다. 두 문서를 합쳐 V1.3으로 사용한다.  
적용 대상: V1~V5 및 이후 모든 제출본  
변경 사유: 자연스러운 문체와 별개로, 동일 프롬프트를 사용하면 누구나 재생산할 수 있는 전형적 답안 구조를 평가할 기준이 부족했음

## 1. 새로 구분하는 세 개념

| 개념 | 질문 | 평가 방식 |
|---|---|---|
| AI 문체 위험 | 문장이 생성형 AI 초안처럼 읽혀 독해와 신뢰를 방해하는가 | 낮음·중간·높음 진단. 실제 영향은 D1·D2에서만 반영 |
| AI 생성 용이성 | 동일 과제와 일반적인 프롬프트만 주면 비슷한 문제·기능·지표 구조가 쉽게 재생산되는가 | 낮음·중간·높음 필수 진단 |
| 판단 소유권·과제 특화성 | 지원자만의 근거, 선택, 제외, 반증, 조건부 판단이 있어 전형적 구조를 자기 판단으로 전환했는가 | D3 4점에서 채점 |

세 개념은 서로 다르다.

- 문체가 자연스러워도 생성 용이성은 높을 수 있다.
- 기능이 전형적이어도 사용자 근거와 비전형적 트레이드오프가 강하면 판단 소유권은 높을 수 있다.
- AI를 사용했더라도 핵심 판단을 지원자가 이해하고 방어하면 자동 감점하지 않는다.
- 사람이 혼자 쓴 글이어도 일반론과 전형적인 제품 구조뿐이면 생성 용이성은 높게 판정할 수 있다.

## 2. V1.2 D3 교체

V1.2의 `D3. 판단의 소유권과 독립성`을 다음 항목으로 교체한다. 배점은 4점으로 유지하므로 총점과 나머지 항목의 배점은 변하지 않는다.

### D3. 판단 소유권·과제 특화성·대체 불가능성: 4점

평가 대상: 답안이 일반적인 PM·GEO 모범 구조를 조립한 수준을 넘어, 해당 사용자와 문제에 대한 지원자의 고유한 근거·선택·조건부 판단을 보여주는가.

| 수준 | 행동 앵커 |
|---:|---|
| 0 | 핵심 선택의 이유를 확인할 수 없고 문서 내용을 지원자가 설명할 수 있을지 신뢰하기 어려움 |
| 1 | 과제 문구를 문제·기능·지표 제목으로 재배열했거나, 산업·회사·사용자 이름을 바꿔도 거의 그대로 쓸 수 있는 일반론임 |
| 2 | 구체적인 정책과 일부 선택은 있으나 핵심 문제·기능 조합이 전형적이며, 직접 사용자 근거·비전형적 통찰·반증·우선순위 역전 조건이 부족함 |
| 3 | 해당 사용자와 상황에 특화된 제약, 선택, 제외, 실패 조건이 있고 일반적인 기능 구조를 왜 이 방식으로 잘랐는지 추적 가능함 |
| 4 | 수준 3에 더해 직접 관찰 또는 독자적인 근거 해석, 비전형적이지만 방어 가능한 선택, 가장 약한 가정, 반증 시 판단을 바꾸는 조건이 있어 일반 프롬프트만으로 동일한 논리를 재현하기 어려움 |

### D3에서 가점하는 증거

- 실제 사용자 발화·행동·업무 자료 또는 그에 준하는 구체적인 1차 관찰
- 경쟁 제품 기능을 나열하는 데 그치지 않고, 공개 구조 사이의 빈틈을 해당 사용자 문제와 연결한 해석
- 누구나 고를 기능보다 무엇을 의도적으로 버렸는지와 그 비용
- 상식적인 MVP 순서와 다른 선택을 했더라도 그 이유와 검증 방법이 명확함
- 자신의 설계에서 가장 약한 가정과 반증될 경우 바꿀 결정
- 같은 기능이라도 이 사용자·회사 단계에서만 필요한 정책이나 운영 방식

### D3에서 가점하지 않는 것

- 새로운 기능명이나 신조어
- 근거 없는 독창성
- 출처 개수 또는 유명 회사 이름
- 필요 이상의 기술 복잡성
- 개인 경험담 자체
- 문체가 특이하거나 인간적으로 보인다는 인상

독창적이어도 고객 문제와 연결되지 않으면 높은 점수를 주지 않는다. 전형적인 기능이어도 구체적인 사용자 근거와 조건부 판단이 강하면 수준 3~4를 받을 수 있다.

## 3. AI 생성 용이성 필수 진단

총점과 별도로 모든 제출본에서 `낮음 / 중간 / 높음`으로 판정한다. 이는 AI 사용 여부를 단정하는 지표가 아니라, 채용 과제로서 지원자를 구별할 수 있는지를 보는 구별력 진단이다.

### 3-1. 다섯 가지 검사

#### 검사 1. 명사 치환 검사

브랜드, 산업, 사용자 역할 이름만 바꿔도 문제 정의와 기능 구조가 그대로 성립하는가?

- 그대로 성립: 생성 용이성 위험 증가
- 해당 상황의 제약 때문에 핵심 구조가 깨짐: 위험 감소

#### 검사 2. 과제 문구 재배열 검사

과제의 `얼마나, 어떻게 노출되는가`를 `노출 대시보드, 원인·출처 분석`으로 직접 나눈 것 이상의 판단이 있는가?

- 문구와 기능이 1:1로 대응하고 추가 근거가 없음: 위험 증가
- 사용자 업무와 선행 관계 때문에 기능 경계를 다르게 정의함: 위험 감소

#### 검사 3. 표준 PM 템플릿 검사

문제 정의→페르소나→기능 두 개→KPI→5명 테스트라는 구조를 제외한 뒤에도 지원자의 판단이 남는가?

- 표준 목차를 제거하면 고유한 선택이 거의 없음: 위험 증가
- 목차와 무관하게 선택·제외·정책·반증 논리가 남음: 위험 감소

#### 검사 4. 근거-결정 고유성 검사

리서치가 일반적인 시장 설명이나 경쟁사 기능 확인에 그치는가, 아니면 특정 제품 결정을 바꿨는가?

- 근거를 다른 GEO 도구 문서로 바꿔도 결론이 같음: 위험 증가
- 특정 근거가 빠지면 기능·정책·우선순위가 실제로 달라짐: 위험 감소

#### 검사 5. 반증·역전 검사

어떤 사용자 증거가 나오면 현재 문제 정의, 기능 또는 우선순위를 바꿀지 명시했는가?

- 무엇이 나와도 현재 구조를 유지함: 위험 증가
- 반증 조건과 바꿀 결정이 연결됨: 위험 감소

### 3-2. 생성 용이성 등급

| 등급 | 판정 기준 |
|---|---|
| 낮음 | 다섯 검사 중 네 개 이상에서 과제 특화 판단이 확인되고, 동일 결론을 내려면 지원자의 근거와 판단 과정이 필요함 |
| 중간 | 핵심 기능은 전형적이지만 범위·정책·트레이드오프 중 일부가 사용자 상황에 특화되어 있음 |
| 높음 | 과제 문구가 전형적인 문제·기능·KPI 구조로 곧바로 변환되고, 사용자 근거와 반증 조건 없이 일반 프롬프트로 유사 답안을 쉽게 만들 수 있음 |

등급 판정에는 최소 세 가지 검사 결과와 제출본의 직접 근거를 기록한다.

## 4. 점수와 선발 판정에 반영하는 방법

1. 생성 용이성 등급 자체는 총점에서 별도로 감점하지 않는다.
2. 답안 대체 가능성이 실제로 높고 판단 근거가 부족하면 D3 행동수준에 반영한다.
3. B3의 우선순위 감점과 같은 원인을 D3에서 다시 감점하지 않는다.
   - B3: 선택한 두 기능의 우선순위 논리가 타당한가
   - D3: 답안 전체가 해당 사용자·상황에 특화된 근거와 판단을 갖는가
4. 생성 용이성 `높음`이면 면접에서 문서 소유권과 적응적 판단을 반드시 검증한다.
5. 문서 소유권 면접이 수준 2 이하이면 과제 총점과 관계없이 `소유권 미검증`으로 진행 비권고할 수 있다.
6. 전형적인 해결책이라는 이유만으로 탈락시키지 않는다. 단순성과 정석은 결함이 아니며, 해당 상황에서 왜 정석이 맞는지 근거가 있으면 통과할 수 있다.

## 6. V5에 대한 V1.3 적용 예시

### AI 문체 위험: 낮음

한국어 문장은 자연스럽고, 기호·굵은 글씨·대칭 구조가 독해를 방해하지 않는다. 구체적인 정책과 제외 결정도 있어 단순한 AI 문체 위험은 낮다.

### AI 생성 용이성: 높음

근거:

1. `얼마나 노출되는가`는 노출·추천 추세 기능으로, `어떻게 노출되는가`는 설명·출처 진단 기능으로 직접 전환됐다.
2. 브랜드 매니저·콘텐츠 마케터, 주간 회의, 대시보드 확인이라는 구조는 1차 사용자 근거 없이 일반적인 B2B 마케팅 업무 흐름으로 설정됐다.
3. 문제 정의→두 페르소나→두 기능→활성화 KPI→5명 수동 테스트는 전형적인 PM 과제 구조다.
4. 참고 자료는 경쟁 도구의 공개 기능 패턴을 확인하지만, 특정 자료가 현재 두 기능의 우선순위를 바꾼 흔적은 약하다.
5. 알림과 개선안을 제외한 이유는 있으나 어떤 사용자 증거가 나오면 핵심 기능 조합 자체를 바꿀지는 명시되지 않았다.

### 판단 소유권·과제 특화성: 수준 2, 2/4점

V5에는 수집 실패 제외, API·소비자 화면 분리, 자동 오류 확정 금지, 수동 운영 우선처럼 구체적인 제품 판단이 있다. 따라서 과제 문구만 재배열한 수준 1은 아니다.

그러나 핵심 문제와 두 기능의 조합은 일반적인 GEO 모니터링 제품 구조이며, 직접 사용자 근거, 비전형적 통찰, 핵심 구조를 바꿀 반증 조건이 없다. V1.3 D3에서는 수준 2가 적절하다.

V1.3 적용 시 V5의 D3는 기존 3점에서 2점으로 변경되며 총점은 **83점에서 82점**으로 조정된다.

## 7. 변경 통제

- V1.3은 이 개정 이후 평가에 적용한다.
- V1.2 점수와 V1.3 점수를 혼용하지 않는다.
- V1~V5 비교 시 모두 V1.3 D3와 생성 용이성 진단을 소급 적용한다.
- 생성 용이성 진단을 이유로 다른 항목을 추가 감점하지 않는다.
- 새로운 답안이 전형적이거나 독특하다는 인상만으로 등급을 정하지 않고 다섯 검사 결과를 기록한다.

### 변경 기록

- 1.3: AI 문체 위험과 AI 생성 용이성을 분리하고, D3를 판단 소유권·과제 특화성·대체 불가능성으로 교체했다. 총배점은 100점으로 유지했다.

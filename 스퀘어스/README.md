## 답안을 관통하는 축

```text
고객 문제·기대 결과
→ 목표 질문 승인
→ 같은 조건에서 반복 측정
→ BM이 노출·추천 흐름의 변화 판단
→ 콘텐츠 마케터가 원문·브랜드 설명·출처 확인
→ 추가 조사 필요 또는 이상 없음 판단
→ 다음 측정 주기에 재확인
```

| 문항 1 | 문항 2 | 성공 측정 |
|---|---|---|
| 중요한 질문에서 발견되는가 | 기능 1. 핵심 질문별 노출 및 추천 흐름 진단 | 질문별 노출률과 기간별 변화 확인 |
| 선택이 필요한 질문에서 추천되는가 | 기능 1. 핵심 질문별 노출 및 추천 흐름 진단 | 추천률과 경쟁사별 차이 확인 |
| 실제 제품과 맞게 설명되는가 | 기능 2. 브랜드 설명과 출처 진단 | 근거를 본 뒤 조사 필요 또는 이상 없음 판단 |

## V5 제출 범위

- 첫 파일럿은 한국어, 한 브랜드, 한 측정 환경, 사용자가 승인한 소수의 목표 질문에 한정한다.
- 첫 검증은 Concierge MVP로 진행하고 반복되는 수동 단계부터 자동화한다.
- 기능 1의 출력은 질문별 노출 및 추천 흐름, 기능 2의 출력은 기대한 브랜드 설명과 실제 답변의 차이 및 출처로 닫는다.
- 재확인은 기능 1을 다시 사용하는 흐름이며 별도 세 번째 기능으로 세지 않는다.
- 자동 질문 생성, 자동 사실 비교, 실시간 알림, 콘텐츠 생성과 게시, 고급 공유, 다중 브랜드와 국가 운영은 MVP 이후로 둔다.
- 종합점수 하나보다 질문별 결과와 답변 원문을 먼저 보여준다.
- V1의 점수 산식·상태 관리·API와 UI 운영 설계는 탐색 이력과 후속 검토 자료로만 보존한다.
- V5 승인 전까지 Word와 PDF는 만들지 않는다.

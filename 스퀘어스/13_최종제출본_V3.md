## 문항 1. “GEO를 잘 하고 있다”는 것은 무엇을 의미하는가

제가 생각하는 좋은 GEO는 잠재 고객이 실제로 물을 만한 질문에서 브랜드가 자주 발견되고, 경쟁 제품과 함께 검토할 만한 선택지로 추천되며, 그 이유와 근거가 실제 제품 정보와 일치하는 상태입니다.

이를 세 가지 기준으로 나누면 다음과 같습니다.

| 기준 | 좋은 상태 | 확인 방법 |
|---|---|---|
| 1. 중요한 질문에서 발견되는가 | 타깃 고객의 문제 탐색, 비교, 구매 검토 질문에서 브랜드가 꾸준히 등장한다 | 질문별 노출률, AI 서비스별 차이, 기간별 추이 |
| 2. 경쟁사와 비교해 선택되는가 | 단순히 이름만 언급되는 것이 아니라 적합한 선택지로 추천되고, 경쟁사보다 뒤처지는 질문이 줄어든다 | 질문별 추천률, 경쟁사 대비 언급 비중 |
| 3. 정확하고 신뢰할 수 있게 설명되는가 | 실제 강점과 적합한 고객이 올바르게 설명되고, 가격이나 기능에 사실 오류가 없다 | 등장 맥락, 주요 속성, 사실 오류, 답변에 표시된 출처 |

### 기준 1. 중요한 질문에서 발견되는가

모든 질문의 무게는 같지 않습니다. “협업툴이란 무엇인가”보다 “50명 규모의 국내 스타트업이 쓸 협업툴을 추천해줘”가 실제 제품 검토와 더 가깝습니다. 따라서 전체 언급 수를 세기 전에 우리 고객이 어떤 상황에서 어떤 질문을 할지 정해야 합니다.

그다음에는 질문별로 브랜드가 등장한 답변의 비율을 봅니다. AI 서비스와 시점에 따라 결과가 달라질 수 있으므로, 한 번의 답변이나 전체 평균만으로 판단하지 않고 같은 질문을 일정한 조건에서 반복해 추이를 확인해야 합니다.

### 기준 2. 경쟁사와 비교해 선택되는가

브랜드가 등장했다고 해서 모두 좋은 노출은 아닙니다. 여러 제품을 나열한 답변의 끝에 이름만 포함된 경우와, 사용자 조건에 맞는 제품으로 먼저 추천된 경우는 가치가 다릅니다.

따라서 노출률과 함께 추천 여부, 답변 안의 등장 위치, 경쟁사 대비 언급 비중을 봐야 합니다. 예를 들어 전체 노출률은 높지만 구매 검토 질문에서 경쟁사만 주로 추천된다면 GEO를 잘하고 있다고 보기 어렵습니다.

### 기준 3. 정확하고 신뢰할 수 있게 설명되는가

지원하지 않는 기능이나 오래된 가격으로 추천되면 높은 노출이 오히려 고객 혼란을 만들 수 있습니다. 제품의 실제 강점, 적합한 고객, 가격과 기능이 공식 정보와 맞는지 확인해야 합니다.

답변에 표시된 출처도 함께 봅니다. 브랜드는 언급되지만 자사나 신뢰할 만한 제3자 자료가 근거로 사용되지 않을 수 있고, 반대로 자사 콘텐츠가 출처로 쓰이지만 브랜드 이름은 드러나지 않을 수도 있습니다. 이 차이를 알아야 공식 정보를 고칠지, 외부 비교 자료를 보완할지 판단할 수 있습니다.

세 기준은 모두 미리 정한 질문과 AI 서비스 안에서 반복 측정한다는 전제가 필요합니다. 그래야 우연히 잘 나온 답변 한 건을 성과로 오해하지 않을 수 있습니다.

## 문항 2. AI 답변 속 브랜드 노출 진단 PRD

### 1. 제품 개요

핵심 사용자는 구독형 협업툴의 SEO, 콘텐츠, 브랜드 업무를 맡는 B2B SaaS 마케팅 담당자입니다. 이 담당자가 중요한 질문에서 자사 브랜드가 얼마나 노출되고, 어떤 맥락과 출처로 설명되는지 한곳에서 확인하게 하는 것이 제품의 목표입니다.

첫 버전은 한국어 질문과 단일 브랜드를 대상으로 합니다. 인터뷰에서 사용 빈도가 높은 것으로 확인된 AI 서비스 두 곳부터 지원하고, 핵심 질문별 노출 모니터링과 답변 맥락 및 출처 분석만 제공합니다.

### 2. 문제 정의와 가설

담당자는 대표나 영업팀으로부터 “ChatGPT에서 우리 서비스는 어떻게 나오나요?”라는 질문을 받습니다. 직접 여러 질문을 입력해 볼 수는 있지만 결과가 매번 달라 현재 상태를 설명하기 어렵습니다. 경쟁사는 얼마나 자주 등장하는지, 자사는 추천인지 단순 언급인지, 어떤 정보를 근거로 답하는지도 스크린샷 몇 장만으로는 비교하기 어렵습니다.

이 문제를 두 가지 가설로 나눴습니다.

1. 같은 핵심 질문을 정기적으로 수집해 질문과 AI 서비스별 노출 수치를 보여주면, 담당자는 수작업 검색 없이 자사의 강한 영역과 약한 영역을 설명할 수 있다.
2. 수치에서 실제 답변과 출처까지 이어서 보여주면, 담당자는 브랜드가 어떤 이유로 소개되는지 확인하고 다음에 조사할 문제를 정할 수 있다.

Gewriter는 구매 여정별 질문에서 브랜드와 도메인 노출을 측정합니다. Profound와 Peec AI는 프롬프트별 노출과 경쟁 지표를 실제 답변 및 출처와 연결합니다. 공개 기능을 비교해 보면 질문 수집, 노출 비교, 원문과 출처 확인이 시장의 기본 구조에 가깝습니다. 다만 이 사례는 구현 방향을 정할 때만 참고하고, 사용자가 실제로 두 기능을 필요로 하는지는 인터뷰와 프로토타입으로 확인하겠습니다.

### 3. 핵심 사용자와 사용 시나리오

이 사용자는 GEO 전담자가 아닙니다. 제품에 매일 오래 머무르기보다 주간 회의 전에 현재 상태와 눈에 띄는 문제를 빠르게 확인하려는 사람으로 가정했습니다.

월요일 회의를 앞두고 담당자가 지난주 리포트를 엽니다. “국내 50인 이하 스타트업용 협업툴 추천” 질문에서 자사 노출률이 낮고 특정 경쟁사가 자주 먼저 등장한 것을 확인합니다. 해당 항목을 누르자 실제 답변에서 자사는 단순 메신저로 설명됐고, 경쟁사는 프로젝트 관리 기능 때문에 추천된 것을 볼 수 있습니다. 담당자는 원문과 출처를 확인한 뒤 제품 정보 오류인지, 외부 비교 자료의 부족인지 추가로 확인할 이슈를 저장합니다.

### 4. 기능 1. 핵심 질문별 AI 노출 모니터링

사용자가 중요하게 보는 질문을 기준으로 자사와 경쟁사의 노출 상태를 정기적으로 수집하고 비교하는 기능입니다. 담당자의 “얼마나 노출되는가”에 답합니다.

| 구분 | 요구사항 |
|---|---|
| 설정 | 브랜드명과 별칭, 자사 도메인, 주요 경쟁사, 대상 고객과 사용 상황을 입력한다 |
| 질문 구성 | 제품이 문제 탐색, 대안 탐색, 비교, 구매 검토 단계의 질문을 제안하고 사용자가 수정하거나 제외한 뒤 확정한다 |
| 수집 | 확정한 질문을 선택한 AI 서비스에 정기적으로 실행하고 서비스와 표시된 모델, 언어, 실행 시각, 검색 사용 여부, 성공 여부, 답변 원문, 표시된 출처를 저장한다 |
| 분석 | 유효한 답변 중 자사가 등장한 비율, 추천된 비율, 경쟁사 대비 언급 비중을 질문과 AI 서비스별로 계산한다 |
| 화면 | 전체 평균보다 질문별 결과를 먼저 보여주고, 기간과 AI 서비스, 질문 주제로 필터링할 수 있게 한다 |
| 예외 | 수집 실패는 미노출로 계산하지 않는다. 수집 경로나 모델 조건이 달라지면 같은 추이로 합치지 않고 화면에 표시한다 |

노출률은 자사가 등장한 유효 답변 수를 전체 유효 답변 수로 나눈 값입니다. 추천률은 전체 유효 답변 중 자사가 사용자 조건에 맞는 선택지로 명시된 답변의 비율로 정의합니다. 초기에는 사람이 표본을 확인해 자동 분류가 이 정의를 지키는지 검증합니다.

기본 수집 주기는 주 1회로 두고, 첫 화면에는 종합 점수 하나보다 질문별 노출률, 추천률, 경쟁사 대비 언급 비중, 최근 변화를 나란히 보여줍니다. 사용자가 수치의 근거를 확인할 수 있도록 모든 집계값은 실제 답변으로 이동할 수 있어야 합니다.

완료 기준은 별도 설명 없이 5분 안에 자사가 강한 질문, 약한 질문, 가장 자주 등장한 경쟁사를 찾을 수 있는 상태입니다.

### 5. 기능 2. 답변 맥락과 출처 분석

기능 1에서 선택한 질문의 실제 답변을 분석해 브랜드가 어떤 역할과 이유로 설명됐는지 보여주는 기능입니다. 담당자의 “어떻게 노출되는가”에 답합니다.

| 구분 | 요구사항 |
|---|---|
| 등장 맥락 | 자사와 경쟁사를 추천, 비교 후보, 단순 언급, 주의 또는 비추천으로 구분한다 |
| 설명 속성 | 반복해서 등장한 강점, 약점, 적합한 고객, 추천 또는 제외 이유를 묶어 보여준다 |
| 사실 확인 | 가격, 기능, 지원 범위처럼 확인 가능한 문장을 표시하고 사용자가 공식 정보와 다른 내용을 신고할 수 있게 한다 |
| 출처 | 답변에 표시된 도메인과 URL을 자사, 경쟁사, 제3자 자료로 나눠 보여준다 |
| 근거 | 자동 판정마다 근거가 된 원문 문장을 함께 보여주며, 사용자가 수정하거나 판단 보류할 수 있게 한다 |
| 결과 저장 | 담당자가 확인이 필요한 답변과 출처를 이슈로 저장하고 내부 공유 링크를 만들 수 있게 한다 |

이 기능은 노출 원인을 자동으로 확정하거나 콘텐츠를 대신 작성하지 않습니다. 답변이 실제로 어떤 표현과 출처를 사용했는지 보여주고, 담당자가 확인할 대상을 좁히는 데 집중합니다.

완료 기준은 특정 질문에서 자사가 어떤 역할로 소개됐는지, 그 판단의 근거 문장과 확인할 출처가 무엇인지 5분 안에 설명할 수 있는 상태입니다.

### 6. 두 기능을 최우선으로 정한 이유

첫 번째 이유는 사용자 요구와 바로 연결되기 때문입니다. 기능 1은 “얼마나 노출되는가”에 답하고, 기능 2는 “어떻게 노출되는가”에 답합니다.

두 번째 이유는 선행 관계입니다. 기능 1이 질문과 답변 데이터를 만들지 못하면 기능 2도 분석할 대상이 없습니다. 반대로 수치만 있고 원문과 출처를 볼 수 없다면 담당자는 왜 그런 결과가 나왔는지 설명하기 어렵습니다.

세 번째 이유는 개발 전에도 가치를 시험할 수 있기 때문입니다. 운영자가 질문을 실행하고 답변을 분류하면, 자동 수집이나 복잡한 분석 모델을 만들기 전에도 사용자가 두 결과를 실제 회의와 조사에 쓰는지 확인할 수 있습니다.

이 담당자에게 지금 필요한 것은 콘텐츠를 더 많이 만드는 기능이 아닙니다. 먼저 어느 질문에서 경쟁사에 밀리는지, 자사 브랜드가 어떤 이유로 설명되는지 알아야 합니다. 그래서 자동 콘텐츠 생성과 게시, 자동 개선안, 실시간 알림, 여러 국가와 브랜드의 통합 관리는 첫 버전에서 제외합니다.

### 7. 프로토타입과 검증 방법

기능을 개발하기 전에 두 단계로 가설을 확인하겠습니다.

첫째, 유사한 업무를 맡는 B2B SaaS 마케팅 담당자 5명에게 최근 AI 답변을 직접 확인한 경험을 묻습니다. 어떤 질문을 사용했고, 결과를 어떻게 정리했으며, 그 결과로 실제 어떤 결정을 했는지 확인합니다. 여기서 반복되는 문제가 없다면 질문 구성과 기능 우선순위를 다시 정합니다.

둘째, 운영자가 질문 실행과 답변 분류를 수동으로 처리한 프로토타입을 2주간 제공합니다. 사용자는 핵심 질문을 확정하고 결과 화면만 사용합니다. 다음 세 가지 과업을 도움 없이 수행할 수 있는지 봅니다.

1. 자사가 강한 질문과 약한 질문을 찾는다.
2. 가장 자주 등장한 경쟁사와 차이가 큰 질문을 찾는다.
3. 문제 답변에서 자사의 등장 맥락, 근거 문장, 확인할 출처를 찾는다.

5명 중 4명 이상이 세 과업을 완료하고, 3명 이상이 다음 측정 결과를 다시 보거나 내부에 공유하겠다고 판단하면 자동화 개발을 진행합니다. 반대로 수치의 의미를 이해하지 못하거나 답변 원문까지 확인하지 않는다면 화면 구조와 기능 2의 필요성을 다시 검토합니다. 이 수치는 시장 기준이 아니라 첫 개발 여부를 정하기 위한 내부 판단선입니다.

### 8. 성공 측정 기준

초기 핵심 지표는 첫 리포트를 본 뒤 7일 안에 근거 문장과 출처가 포함된 이슈를 하나 이상 저장하거나 공유한 계정 비율입니다. 단순 조회보다 결과가 실제 조사와 보고에 쓰였는지를 확인하기 위해서입니다.

| 구분 | 지표 | 확인하려는 것 |
|---|---|---|
| 첫 가치 | 질문 확정부터 첫 리포트 확인까지 걸린 시간과 완료율 | 설정 과정이 과도하지 않은가 |
| 이해 | 도움 없이 강한 질문, 약한 질문, 주요 경쟁사를 찾은 사용자 비율 | 기능 1이 현재 상태를 설명하는가 |
| 분석 사용 | 현황에서 답변 원문과 출처까지 확인한 계정 비율 | 기능 2가 실제로 필요한가 |
| 반복 가치 | 다음 측정 주기에 다시 방문한 계정 비율 | 일회성 보고서가 아닌가 |
| 분석 품질 | 표본에서 사람 검수와 등장 맥락 판정이 일치한 비율, 판단 보류 비율 | 자동 분석을 신뢰할 수 있는가 |

브랜드 노출률 상승은 초기 제품 성공 지표로 두지 않습니다. 제품은 먼저 측정과 진단을 제공하며, 외부 AI 서비스의 변화까지 통제할 수 없기 때문입니다. 노출 개선은 고객이 이후 개선 행동을 실행하고 충분한 기간의 데이터가 쌓인 뒤 고객 결과 지표로 확인하겠습니다.
